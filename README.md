# aston-team-project

Консольное Java-приложение для работы со списком студентов: заполнение данными, валидация, сортировка, запись в файл и подсчёт совпадений в нескольких потоках.

## Возможности

- **Заполнение списка** тремя способами: из файла, случайными данными, вручную с клавиатуры.
- **Валидация** каждого студента (группа и номер зачётки не пустые, средний балл от 0 до 5).
- **Вывод** списка студентов.
- **Сортировка** по среднему баллу, группе или номеру зачётки двумя алгоритмами: вставками и быстрой.
- **Дополнительные функции:**
  - кастомная сортировка: сортируются только студенты с чётной целой частью среднего балла, остальные остаются на местах;
  - запись списка в файл;
  - многопоточный подсчёт совпадений студента в списке.

## Модель данных

Студент (`Student`) состоит из трёх полей:

| Поле | Тип | Описание |
|------|-----|----------|
| `group` | String | Группа |
| `averageGrade` | double | Средний балл (0–5) |
| `recordBook` | String | Номер зачётной книжки |

## Структура проекта

```
ru.aston.project
├── Main                 точка входа, запускает ConsoleApplication
├── app                  ConsoleApplication: меню и работа с пользователем
├── collection           CustomList: собственная реализация List<Student>
├── io                   DataReader, DataWriter, StreamDataReader: чтение и запись
├── model                Student
├── strategy             алгоритмы сортировки (InsertionSort, QuickSort, EvenOddSort)
│   ├── comparator       компараторы по баллу, группе и зачётке
│   └── enums            SortField: выбор поля сортировки
├── threads              MultiThreadCounter: подсчёт в нескольких потоках
└── validator            цепочка валидаторов студента
```

## Запуск

Нужны Java (с поддержкой switch-выражений и pattern matching, 17+) и Maven.

```
mvn compile
```

Запустите класс `ru.aston.project.Main` из IDE (IntelliJ IDEA) или через Maven.


## Тестирование

Проект покрыт юнит-тестами с использованием **JUnit 5**.
Тесты разделены по слоям и проверяют граничные случаи (`null`, пустые списки, выход за границы массива).
- `CustomListTest` — проверка расширения массива, удаления, сдвигов.
- `StudentTest` — проверка Билдера, контрактов `equals`, `hashCode` и `toString`.
- `StudentValidatorServiceTest` — проверка границ (0.0, 5.0) и неверных данных.
- `ComparatorTest` — проверка компараторов и обработки `null`.
- `SortStrategyTest` / `EvenOddSortTest` — проверка алгоритмов сортировки.
- `DataReaderTest` / `FileDataReaderTest` / `StreamDataReaderTest` — проверка чтения из файла и ресурсов.
- `StudentParserTest` — проверка парсинга строк и валидации.
- `DataWriterTest` — проверка записи в файл (режим добавления).
- `MultiThreadCounterTest` — проверка многопоточного поиска.

## Формат файла со студентами

Каждая строка файла: `группа,средний балл,номер зачётки`. Балл пишется через точку.

```
ИТ-101,4.5,123456
ПИ-201,3.8,654321
```

По умолчанию при выборе «Из файла» читается файл `students.txt` из папки src/main/resources.

## Как пользоваться

После запуска появится меню:

```
1. Заполнить список студентов
2. Вывести список студентов
3. Отсортировать студентов
4. Дополнительные функции
0. Выход
```

Выберите пункт, введите номер и следуйте подсказкам в консоли.
